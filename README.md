# Proforma-Study-Scheduler
Proforma Study Scheduler: A study scheduler that sort itself based on proforma given and users free time, which can be customized, adjusted, and changed based on users needs. The goals is flexibility, personified without stressing users.

1. Uses Python as main environment
2. Pydantic as validator,structure and PdfPlumber as pdf reader/extractor 
3. Uses .ics for calander
4. Ortools for scheduler
5. Ollama for chatbot, utilizing qwen 2.5:7b model
6. Streamlit for easy network deployment and basic UI
